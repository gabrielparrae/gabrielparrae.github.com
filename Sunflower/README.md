# 🌻 Flores Amarillas - 21 de Septiembre 💛

Una hermosa aplicación web romántica dedicada especialmente para regalar flores amarillas en el día más especial del año.

## ✨ Características

- **Diseño romántico y elegante** con flores amarillas animadas
- **Efectos interactivos** con partículas mágicas y animaciones
- **Mensaje personalizado** para el 21 de septiembre
- **Completamente responsive** - se ve perfecto en móviles y escritorio
- **Múltiples sorpresas** al hacer clic en el botón mágico
- **Animaciones suaves** y efectos de paralaje

## 🎯 Efectos Especiales

### Al hacer clic en el botón mágico:
1. **Primera sorpresa**: Mensaje personal romántico
2. **Segunda sorpresa**: Flores que brillan con efectos de luz
3. **Tercera sorpresa**: Lluvia de flores desde el cielo
4. **Cuarta sorpresa**: Texto con colores arcoíris
5. **Sorpresas adicionales**: Efectos aleatorios continuos

### Otros efectos:
- **Flores flotantes** que se mueven suavemente
- **Efecto de paralaje** que sigue el movimiento del mouse
- **Animaciones de respiración** en las flores principales
- **Partículas brillantes** de fondo
- **Corazón interactivo** que brilla al pasar el mouse

## 🚀 Cómo usar

1. **Abrir la aplicación**: Simplemente abre `index.html` en tu navegador web
2. **Disfrutar las animaciones**: Las flores se mueven suavemente y hay efectos de fondo
3. **Hacer clic en el botón mágico**: Cada clic revela una nueva sorpresa
4. **Interactuar con elementos**: Pasa el mouse sobre el corazón y otros elementos
5. **Compartir**: ¡Perfecto para regalar el 21 de septiembre!

## 📱 Compatibilidad

## 🎨 Personalización

Puedes personalizar fácilmente:

### Cambiar el mensaje:
Edita el archivo `index.html` en la sección `.romantic-message` y `.message-box`

### Modificar colores:
Ajusta las variables de color en `styles.css`:
- Flores: `#fdcb6e`, `#ffeaa7` (tonos amarillos)
- Fondo: `linear-gradient(135deg, #ffeaa7 0%, #fdcb6e 50%, #e17055 100%)`
- Texto: `#2d3436`, `#e17055`

### Agregar más efectos:
Modifica `script.js` para incluir nuevas animaciones o sorpresas
